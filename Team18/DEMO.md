# 小番茄 · 专注时光 Demo

1. 在 Android Studio 中打开本目录，等待 Gradle 同步，然后运行到模拟器或安卓手机。
2. 首页点击“任务清单”，输入“复习 CSI301”并添加；点击任务后返回专注首页，当前任务应同步更新。
3. 首页右上角点击“设置节奏”，把专注时长设为 1 分钟并保存，然后点击“开始专注”。
4. 观察环形进度和倒计时；可暂停、继续，切到其他应用后返回也会按目标结束时间更新。
5. 完成后检查弹窗；点击“专注回顾”查看今日统计、最近七天图表和完成记录。弹窗中的“开始休息”会切换到休息模式。
6. 长按任务可编辑名称、标记完成或删除。需要提前结束时点击“结束”，该轮不会计入记录。

课件知识对应：显式 Intent 负责页面跳转；首页 onResume 生命周期回调重新读取任务；回顾页的 ReviewLoader 在 Thread 中查询 SQLite，通过自定义 Callback 和主线程 Handler 返回结果；Canvas 绘制环形进度和七天图表。结束弹窗只在 App 前台运行时可靠显示；后台准点通知尚未实现。
