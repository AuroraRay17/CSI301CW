# CSI301 Team 18 专注小窝

Android Studio 项目位于 [Team18](Team18/)。应用使用课程课件涵盖的 Java、XML、Activity、Handler、SharedPreferences 与 SQLiteOpenHelper。

## 当前功能

- 启动后进入铺满主页的阳光房间。垂耳兔侧趴在木地板上，待机时约每 4 秒呼吸一轮。点兔头可触发已解锁的「摸摸头」并显示爱心，尚未解锁时会显示提示。点手掌气泡可触发已解锁的「打招呼」。可以改名或使用已拥有的软垫。成长记录位于右上角，底部菜单提供专注计时、任务、商店、复盘与设置。
- 在专注计时中选择番茄钟或正计时。两种模式都支持暂停和继续，确认结束后按实际专注时长结算。页面底部固定显示「复盘」和「设置」。
- 番茄钟页的左侧红圈是专注时长，右侧绿圈是休息时长。开始前可点选相邻的浅色数字或上下滑动，每一位都能首尾循环。支持 `00:00:00` 到 `23:59:59`，零时长无法启动对应的倒计时。
- 番茄钟使用同样的数字控件设置 1–10 轮，1 和 10 可相互循环。每轮按专注、休息的顺序自动运行，最后一次休息结束后停止。休息设为零时直接跳过休息。
- 多轮番茄钟在最后一轮休息结束或确认提前停止时结算一次。休息设为零时，最后一轮专注结束即结算。先合计本次计划的实际专注秒数，再向下取整为分钟。按计划完成乘以 1.5 并向下取整，提前结束按整分钟发放。三轮各 30 秒，合计 90 秒可得 1 金币。
- 正计时与单轮番茄钟按实际专注时长独立结算。正计时和提前结束的单轮番茄钟每分钟 1 金币，按计划完成的单轮番茄钟每分钟 1.5 金币，金币向下取整。暂停和休息时间不计入收益，各次计划的余秒独立计算。
- 小窝商店从主页底部展开，宠物场景等比例缩小。三列商品分成「动作」和「小窝」两区，各有五个位置，可上下浏览或点分类切换。
- 点商品查看价格和场景预览，再点同一商品确认购买。动作每次播完间隔 1.5 秒重播。当前可解锁「打招呼」（5 金币）、「摸摸头」（25 金币）和「蓝色软垫」（15 金币）。
- 「小窝」也用于布置场景。每类布置的第一项是「无」，点已拥有的物品即可布置。浅蓝底和「使用中」标记当前选择，关闭商店或重启后会保留布置。
- 创建、选择、编辑、完成和删除学习任务
- 任务目标番茄数与备注
- 专注与休息计时，支持暂停、继续和提前结束
- 界面使用晴空蓝、浅紫和白色，标题与按钮使用站酷快乐体。专注计时的开始按钮可在设置中选择珊瑚粉或晴空蓝。
- 三种本地环境音：雨声、森林鸟鸣、海浪水声；可调音量
- 完成提醒与可点击通知、可选光线和低电量提示
- SQLite 记录每轮的实际秒数、计时模式、完成状态和已购买的物品。多轮计划的金币单独记账，用计划标识防止重复发放。
- 复盘页汇总两种模式的累计专注时长，并保留七天图表、任务分布、连续天数、全部历史和文字周报

## 当前验证状态

当前 [Debug APK](app-debug.apk) 已通过 `assembleDebug`、`assembleRelease`、`testDebugUnitTest` 和 `lintDebug`。独立 Android API 37 模拟器验证了主页互动的解锁、重启恢复，以及普通竖屏、320dp 窄屏和横屏下的点按。计时页、多轮结算和商店的验证见迭代日志。

同签名的旧版覆盖升级保留任务、历史、偏好、金币和已经解锁的互动。升级时正在进行的多轮计划，从尚未记入历史的专注阶段开始合并结算。原始 11 月 18 日 APK 使用了另一把调试签名。通过该 APK 安装的设备需要使用原签名构建新版才能保留数据并覆盖安装，本目录的新 APK 可用于全新安装。
